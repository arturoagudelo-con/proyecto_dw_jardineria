# proyecto_dw_jardineria

este repositorio tiene los archivos completos de cada una de las actividades que se realizaron a través del curso.

## contenido del proyecto

* **`01_actividad_1_modelo_inicial/`**: en esta carpeta contamos con los archivos del diagrama del UML, un avance de lo que podria ser nuestro data mart.
* **`02_actividad_2_staging_y_perfilado/`**: en esta carpeta encontramos la base de datos Staging, con cada una de sus tablas stg(cliente, pedido, pago, producto) los bk(jardineria, Staging_jardineria) la vista transformacion.
* **`03_actividad_3_etl_y_datamart_final/`**: en esta carpeta encontramos los archivos del warehouse con las vistas(cliente, pago, pedido, producto) los archivos de bk(jardineria, Staging_jardineria, dw_jardineria)
* **`04_pruebas_calidad_datos/`**: aqui tenemos las pruebas que son cuadre volumétrico y financiero entre capas, integridad referencial y detección de anomalías.
